# NEU25G-WebDev.NET

Detta repo innehåller kodexempel, code-alongs och övningar från kursen Webbutveckling med .NET.

## Innehåll

### [Code-Along](https://github.com/MelvinEdlund/NEU25G-WebDev.NET/tree/master/Code-Along)
Projekt och genomgångar skapade under lektioner för att lära ut grundläggande och avancerade koncept inom .NET och webbutveckling.

#### Innehåller bland annat
- ASP.NET Core
- React och frontend-integration
- API-utveckling
- CRUD-operationer
- Routing och komponentstruktur
- Databaskopplingar
- Authentication och säkerhet

---

### [Exercises](https://github.com/MelvinEdlund/NEU25G-WebDev.NET/tree/master/Exercises)
Övningsuppgifter och mindre projekt för att träna praktiska moment inom .NET-utveckling och modern webbutveckling.

#### Fokusområden
- C#
- ASP.NET Core
- React
- JavaScript
- SQL och databashantering
- Fullstack-utveckling
- Problemlösning och kodstruktur
